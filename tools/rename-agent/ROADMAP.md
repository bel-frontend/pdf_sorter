# Плануемыя фічы File Garden

## Лакальны каталог і пошук па змесціве

Статус: адкладзена на пазней па рашэнні карыстальніка ад 2026-10-06.

Мэта: знаходзіць ужо прааналізаваныя файлы па іх змесціве і адкрываць іх
з вынікаў пошуку без паўторнага OCR.

Першы этап:

- Захоўваць каталог прывязаных файлаў: актуальныя шляхі, адбіткі змесціва,
  апісанні, катэгорыі, імёны, даты і распазнаны тэкст.
- Выкарыстоўваць метаданыя паспяховых аналізаў з існага кэша.
- Абнаўляць шляхі пасля перайменавання, перамяшчэння і адмены аперацый;
  адзначаць файлы, якія больш не знойдзеныя.
- Дадаць пошук па тэксце і метаданых з магчымасцю адкрыць знойдзены файл.
- Захоўваць каталог лакальна паміж запускамі дадатка.

Наступны этап:

- Дадаць пошук па сэнсе праз лакальны вектарны індэкс, напрыклад па запыце
  «дакументы пра аплату бухгалтара».
- Індэксаваць толькі новыя або змененыя файлы, выкарыстоўваючы захаваны
  аналіз без паўторнага OCR.

Рэалізацыя гэтых этапаў пакуль не пачынаецца.
